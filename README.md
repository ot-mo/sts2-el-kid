# El Kid — a Slay the Spire 2 character mod

A playable character for Slay the Spire 2, built on [BaseLib](https://github.com/Alchyr/BaseLib-StS2). It's a work in progress, and most art is still placeholder.

El Kid is a young duelist who fights between the ticks of the clock. He banks **Time** while playing **Slow**, then spends it to play cards **Fast**.

## Mechanics
- **Time:** El Kid's own resource, shown next to Energy. It carries over between turns, caps at 5 and resets each combat.
- **Dual cards:** most cards have a **FAST** half and a **SLOW** half. SLOW halves usually gain Time. A card played Fast spends 1 Time and uses its FAST half instead.
- **Playing Fast:** **right-click** a dual card in your hand to make that one card Fast. Or press the **FAST/SLOW** button next to Energy to make every dual card Fast until you run out of Time.
- **Blink X:** gain X Block, and your next Attack deals X additional damage.

The starter deck is 4 Strike, 4 Defend, Blink Step and Wind Up. The starter relic is Pocket Watch (start each combat with 1 Time). The card pool has 20 more cards, including Time finishers, Fast-play powers and cards that trade HP for Time.

## Playing it
1. Install BaseLib by subscribing on Steam Workshop, or by putting its `.dll`, `.pck` and `.json` in `Slay the Spire 2/mods/BaseLib/`.
2. Build this mod (see below), or copy a built `ElKid` folder into `Slay the Spire 2/mods/`.
3. Launch with **Play with Mods**, enable **BaseLib** and **ElKid** in the Mods menu, then restart.

## Building
Requirements:
- the .NET 9 SDK
- MegaDot or Godot 4.5.1 .NET (must be exactly 4.5.1, for the `.pck` export)
- Slay the Spire 2 installed

Steps:
1. Copy `Directory.Build.props.example` to `Directory.Build.props` and set `GodotPath`. Also set `Sts2Path` if the game isn't in the default Steam location.
2. Run `dotnet build`. This compiles the `.dll` and copies it to the game's `mods/ElKid/` folder, which is enough for code changes.
3. Run `dotnet publish`. This also exports the `.pck` (art and text) to the mods folder. You need it after any change to images, text or scenes. On a fresh clone, run Godot's import once first: `<godot> --headless --path . --import`.

Close the game before building, because it locks the mod's `.dll`.

The combat sprite rig is generated by `tools/gen_character.py`. Edit the script rather than `ElKid/scenes/el_kid.tscn`.

## Project layout
- `ElKidCode/`: C# code.
  - `Character/` holds the character and its card, relic and potion pools.
  - `Cards/`, `Relics/` and `Powers/` hold the game content.
  - `Time/` holds the Time resource, the Fast/Slow button, right-click priming and shared actions.
- `ElKid/`: assets packed into the `.pck`: `images/`, `localization/eng/` and `scenes/`.
- `tools/`: art generation scripts.

## Known limitations
- Fast mode and right-click priming are local only and not yet synced in multiplayer.
- Most cards, relics and powers use placeholder art.
